# Atul Sharma — Developer Portfolio

Personal developer portfolio website built with React, Vite, and Tailwind CSS.

## 🚀 Tech Stack

- **Framework:** React 19 + Vite
- **Styling:** Tailwind CSS v4
- **Icons:** React Icons

## 🛠️ Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build for Production

```bash
npm run build
```
